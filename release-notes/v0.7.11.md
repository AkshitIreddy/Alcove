## Better PDF reading

PDFs attached to the Agent now use Cohere Parse automatically after the reader
has connected Cohere and accepted the relevant privacy notice. Alcove renders
each page locally, preserving its complete appearance, while Parse recovers
structured headings, reading order, tables and text from scanned pages. This
makes lecture slides, forms and image-only PDFs much more useful for explaining
material or building notebook pages.

## Graceful local fallback

Only bounded page images are sent after a task starts; the PDF file and API key
remain behind Alcove's managed boundaries. If a page cannot render or Cohere is
unavailable, that page keeps Alcove's local extraction instead of making the
whole attachment fail. Cancellation, retries and provider responses remain
strictly bounded.
