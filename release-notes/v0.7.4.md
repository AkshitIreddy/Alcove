## An agent that can reconsider its own route

Alcove’s Agent now owns the semantic outcome of each reader turn instead of
being confined by a keyword decision made before the model sees its tools. At
the undecided boundary, Command A+ can choose a conversational answer or begin
notebook work. Its first successful mode-specific action settles that choice;
later stages narrow back to the single useful workflow gate, keeping the task
fast and resistant to tool churn.

The local intent detector remains as an advisory hint. If the model disagrees,
it can declare the intended mode with a reason and continue. A conflicting
first call is returned to the model as a structured error rather than silently
hiding the other tool family.

## Tool errors now explain how to recover

Every local tool failure now returns an error code, the failed tool, whether
state changed, the complete currently available tool set, suggested recovery
tools and a concrete next action. Command A+ can correct changed arguments,
call a missing prerequisite or explicitly repair task mode on its next turn.
Repeated unchanged failures remain bounded by the no-progress watchdog.

Live Cohere tool streams are now judged by the complete call body rather than
an inconsistent terminal label: Command A+ may finish a valid call with either
`TOOL_CALL` or `COMPLETE`. If the draft envelope itself is malformed, Alcove
asks the same model once for raw Notebook Script and locally restores the
missing draft-only call before normal validation and review.

Unread relevant-only sources no longer expose a misleading “coverage complete”
inspection before the Agent has selected or read evidence. After notebook
intent settles, source intake is exclusive until at least one real read has
completed. If Cohere produces one malformed source-routing stream, Alcove
counts it, sends one corrective turn with the same safe tool boundary, and
continues; a second malformed response still pauses safely.

Transport, authentication, rate limits, protocol validity, stale revisions,
source authority and final Insert approval remain deterministic local
responsibilities. A model cannot weaken those gates or grant itself permission
to edit the book.

## Drag a picture straight into the Agent

Images and source files can be dropped onto either the compact composer or the
larger writing sheet. A clear hand-drawn drop target appears during the drag,
then the file follows the same managed attachment path as the picker. Explicit
requests such as “add this picture” are understood as notebook work without
requiring the reader to repeat the word “book.”

Source and multimodal Cohere turns avoid an incompatible optional strict-schema
wire flag while Alcove’s own schemas continue validating every call. Localhost
also has a byte-bounded, content-addressed image store, so the complete drag,
source-read and native-preview path can be exercised without Tauri.

Reader-supplied pictures can no longer disappear during repair. Alcove pins the
exact managed attachment path across every revised draft, corrects a path that
the model put in the ordinary Markdown URL slot, inserts a canonical image block
when the model omitted it, materialises Tauri
attachment bytes as clone-safe blob media for native capture, and blocks empty,
receipt-only, missing-media or unreadable previews even if the model labels the
finding informational. Copy Logs now retains bounded provider/tool failure
details while continuing to exclude credentials and attachment bytes.

The normal single-image Agent path now uses Command A+ only twice: once to
author the grounded page and once to judge its rendered pixels. Notebook
inspection, source reading, validation, native rendering, image exposure,
proposal construction and preview presentation remain explicit audited tools
but run locally, avoiding rate-limit churn and stale tool-name hallucinations.
A vague “add to my book” defaults to one image-led page rather than expanding a
dense infographic into a chapter.

## Writing-desk zoom happens only when you mean it

Scrolling over the empty field around an open book no longer changes the book's
size merely because the pointer happened to be there. Desk zoom is armed only
by a fresh click on that empty field and expires quickly after the gesture.
Moving onto the pages, opening a panel, typing, switching windows or simply
waiting cancels it, so scrolling the Agent transcript cannot resize the book in
the background. The canonical page layout remains fixed while the camera scale
changes, preserving pagination and block positions.

## Release notes written for the release

GitHub release messages are no longer inferred from commit titles. Each version
must include a checked-in, version-matched note written after the work is done,
with enough detail to explain behavior and impact. The workflow validates that
authored message before it spends time building installers, then publishes it
alongside the standard platform download guidance.
